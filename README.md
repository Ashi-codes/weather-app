# 🌦️ SkyCast - Weather App

A modern and interactive Weather App built using HTML, CSS, and JavaScript.  
It provides real-time weather updates with a clean UI and dynamic background effects.

--------------------------------------------------------------------------------------------------

## 🚀 Features

✔ Real-time weather data using API  
✔ Smart weather interpretation (no confusing terms like "smoke")  
✔ Dynamic background (sunny, cloudy, rainy, hazy)  
✔ Smooth and eye-friendly UI  
✔ Loading animation  
✔ Enter key support  
✔ Responsive design  

-------------------------------------------------------------------------------------------------

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (ES6)  
- OpenWeather API

## 📌 How to Use

1. Enter city name  
2. Click Search or press Enter  
3. View real-time weather data
